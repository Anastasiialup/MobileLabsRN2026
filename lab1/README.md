# 🎀 Лабораторна робота №1: Платформа "FavNews"

### Розробка багатосторінкового мобільного додатка на React Native

Основна мета — опанування базових компонентів React Native, побудова складної навігації та стилізація інтерфейсу з використанням **Styled-components**.

-----

## 🛠 Технологічний стек

  * **Framework:** Expo (React Native)
  * **Navigation:** React Navigation (Stack, Drawer, Bottom Tabs)
  * **Styling:** Styled-components (CSS-in-JS)
  * **Icons:** Expo Vector Icons

-----

## 📋 Реалізований функціонал та модулі

### 1\. Система автентифікації (Auth Flow)

Реалізовано повноцінний екран реєстрації з валідацією полів. Після "реєстрації" дані користувача передаються на екран профілю.

**Приклад коду стилізованого інпуту:**

```javascript
const StyledInput = styled.TextInput`
  width: 100%;
  height: 50px;
  background-color: #ffffff;
  border-radius: 12px;
  padding: 0 15px;
  margin-bottom: 15px;
  border: 1px solid #ffb6c1;
  color: #db7093;
`;
```

### 2\. Складна навігація (Navigation Architecture)

Додаток використовує комбіновану навігацію:

  * **Drawer Navigation:** Бокове меню для швидкого доступу до розділів "Головна", "Галерея" та "Профіль".
  * **Stack Navigation:** Для переходу зі списку новин до конкретної статті.

### 3\. Стрічка новин та пагінація

Екран новин відображає список об'єктів. Реалізовано механізм перемикання між новинами всередині екрана деталей (функціонал "Next/Prev").

**Логіка перемикання новин:**

```javascript
const handleNext = () => {
  if (currentId < newsData.length) {
    navigation.setParams({ id: currentId + 1 });
  }
};
```

### 4\. Фотогалерея (Grid Layout)

Реалізовано відображення зображень у дві колонки з використанням `FlatList` або `ScrollView` з `flex-wrap`. Кожне зображення має закруглені кути та тіні для підтримки загального стилю.

## Інструкція з розгортання

1.  **Клонування:**
    ```bash
    git clone git clone https://github.com/Anastasiialup/MobileLabsRN2026/lab1.git
    ```
2.  **Встановлення пакетів:**
    ```bash
    npm install
    ```
3.  **Бібліотеки навігації (важливо):**
    ```bash
    npm install @react-navigation/native @react-navigation/drawer @react-navigation/stack
    ```
4.  **Запуск:**
    ```bash
    npx expo start
    ```
