# 🎀 Лабораторна робота №2: Вкладена навігація та списки у React Native

[cite_start]Цей проект присвячено опануванню архітектури вкладеної навігації (Nested Navigation) та вивченню методів віртуалізації для ефективного відображення великих масивів даних[cite: 3, 6].

## 🎯 Мета роботи

* [cite_start]Вивчення архітектури вкладеної навігації: Drawer Navigator всередині Stack Navigator або навпаки[cite: 6, 21].
* [cite_start]Опанування компонентів `FlatList` та `SectionList` для роботи з великими списками[cite: 9, 11].
* [cite_start]Реалізація механізмів **Pull-to-Refresh** та **Infinite Scroll**[cite: 63, 67].

## 📋 Реалізований функціонал

### [cite_start]1. Навігаційна структура [cite: 80, 81]

Реалізовано вкладену систему переходів:

* [cite_start]**Drawer Navigator:** Бокове меню для перемикання між основними розділами (Новини, Контакти)[cite: 82, 108, 109].
* [cite_start]**Stack Navigator:** Забезпечує перехід від списку новин (`MainScreen`) до екрана деталей (`DetailsScreen`) із динамічним заголовком та передачею параметрів[cite: 84, 85, 88, 92].
* [cite_start]**Custom Drawer:** Кастомізоване меню з аватаром, ПІБ та назвою групи[cite: 103, 104, 105, 107].

### [cite_start]2. Стрічка новин (FlatList) [cite: 60, 61]

[cite_start]Список новин побудований на базі `FlatList` з використанням віртуалізації для економії пам'яті[cite: 28, 30].

* [cite_start]**Оптимізація:** Налаштовано параметри `initialNumToRender`, `maxToRenderPerBatch` та `windowSize` для стабільної роботи при скролінгу[cite: 75, 76, 77, 79].
* [cite_start]**Pull-to-Refresh:** Оновлення списку жестом зверху вниз[cite: 63].
* [cite_start]**Infinite Scroll:** Підвантаження нових даних при досягненні кінця списку[cite: 67].
* [cite_start]**Компоненти:** Використано `ListHeaderComponent` для шапки та `ItemSeparatorComponent` для розділювачів[cite: 73, 74].

### [cite_start]3. Екран контактів (SectionList) [cite: 94, 95]

[cite_start]Реалізовано відображення контактів, згрупованих за секціями (наприклад, за алфавітом)[cite: 44, 96].

* [cite_start]Використано `renderSectionHeader` для відображення заголовків груп[cite: 100].

## [cite_start]💡 Відповіді на контрольні запитання [cite: 110]

1.  [cite_start]**FlatList vs ScrollView:** `ScrollView` рендерить усі елементи відразу (що погано для пам'яті), тоді як `FlatList` рендерить лише ті, що зараз видно на екрані[cite: 29, 31, 111].
2.  [cite_start]**Віртуалізація:** Це механізм, при якому невидимі елементи списку видаляються з дерева рендерингу для вивільнення ресурсів[cite: 28, 32, 112].
3.  [cite_start]**Передача параметрів:** Здійснюється через другий аргумент функції `navigation.navigate('Route', { params })` та отримується через `route.params`[cite: 113].
4.  [cite_start]**Вкладена навігація:** Це ситуація, коли один навігатор (наприклад, Stack) є екраном всередині іншого навігатора (наприклад, Drawer)[cite: 21, 114].
5.  [cite_start]**Застосування SectionList:** Використовується, коли дані логічно розділені на групи з власними заголовками (наприклад, контакти, розклад)[cite: 44, 45, 115].

## Інструкція з розгортання

1.  **Клонування:**
    ```bash
    git clone git clone https://github.com/Anastasiialup/MobileLabsRN2026/lab2.git
    ```
2.  **Встановлення пакетів:**
    ```bash
    npm install
    ```
3.  **Бібліотеки навігації (важливо):**
    ```bash
    npm install @react-navigation/native @react-navigation/drawer @react-navigation/stack
    ```
4.  **Запуск:**
    ```bash
    npx expo start
    ```
