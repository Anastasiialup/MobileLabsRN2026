# 🎀 Лабораторна робота №4: Mobile File Manager 

### Розробка інтерактивного ігрового застосунку "Gesture Clicker"

[cite_start]Цей проєкт є лабораторною роботою з розробки мобільного додатка для керування файловою системою пристрою. Додаток дозволяє створювати, редагувати, перейменовувати та організовувати файли та папки в ізольованому сховищі додатка.[cite: 124, 125].

-----

## 🎯 Мета роботи

* [cite_start]Навчитися працювати з бібліотекою `react-native-gesture-handler`[cite: 125].
* [cite_start]Реалізувати обробку різних типів жестів: тапи, довгі натискання, перетягування, свайпи та масштабування[cite: 165, 169].
* [cite_start]Застосувати `Styled Components` для створення адаптивного та естетичного інтерфейсу з підтримкою темної/світлої тем[cite: 188].

-----

## 📋 Функціональні вимоги

У додатку реалізовано наступні можливості:
* **Перегляд вмісту**: Відображення списку файлів та папок у поточному каталозі.
* **Створення об'єктів**: Роздільне створення текстових файлів (`.txt`) та нових директорій.
* **Текстовий редактор**: Повноцінний екран для написання та збереження тексту.
* **Навігація**: Можливість переходити вглиб папок та повертатися на рівень вище.
* **Операції з файлами**: Перейменування та видалення через контекстне меню (довге натискання).
* **Безпека даних**: Кастомне модальне вікно підтвердження перед видаленням об'єктів.
* **Моніторинг пам'яті**: Виведення статистики про загальний та вільний обсяг дискового простору.

## 🛠 Технологічний стек

* **React Native & Expo**: Основна платформа розробки.
* **Expo FileSystem**: Робота з локальною файловою системою (API `DocumentDirectory`).
* **React Navigation (Stack)**: Управління переходами між екраном провідника та редактором.
* **Styled Components**: Декларативний підхід до стилізації інтерфейсу.
* **React Native Safe Area Context**: Адаптація інтерфейсу під вирізи (notch) та системні панелі різних пристроїв.

## 📸 Особливості інтерфейсу

* **Custom Modals**: Замість стандартних системних діалогів використовуються стилізовані модальні вікна, що забезпечує єдиний дизайн (UI/UX) на обох платформах.
* **FAB (Floating Action Buttons)**: Дві плаваючі кнопки для швидкого доступу до створення папок 📂 та файлів ➕.
* **Visual Stats**: Кольорове маркування статусу пам'яті (Вільно — зелений, Зайнято — рожевий).

## 🏗 Структура проєкту

```text
├── App.js                 # Конфігурація навігації та вхідна точка
├── src/
│   ├── screens/
│   │   ├── FileManager.js # Головний екран провідника
│   │   └── FileEditor.js  # Екран текстового редактора
│   ├── components/
│   │   └── FileItem.js    # Компонент відображення одиниці файлу/папки

└── assets/                # Графічні ресурси додатка
```

## Інструкція з розгортання

1.  **Клонування:**
    ```bash
    git clone https://github.com/Anastasiialup/MobileLabsRN2026/lab3.git
    ```
2.  **Встановлення пакетів:**
    ```bash
    npm install
    ```
3.  **Бібліотеки навігації (важливо):**
    ```bash
    npm install @react-navigation/native @react-navigation/drawer @react-navigation/stack
    ```
4.  **Запуск:**
    ```bash
    npx expo start
    ```

## 📝 Висновки

Ось стислий висновок для лаби:

### Висновок
Під час виконання лабораторної роботи було створено мобільний додаток **«Мій Провідник»** на базі **React Native** (Expo).

**Результати:**
* **FileSystem**: Реалізовано повний цикл роботи з файлами та папками (створення, читання, перейменування, видалення) через `expo-file-system`.
* **Навігація**: Налаштовано переходи між провідником та редактором за допомогою `React Navigation`.
* **Інтерфейс**: Створено кастомний дизайн з використанням `styled-components`, адаптований під вирізи екрана (`Safe Area`).
* **Безпека**: Впроваджено систему модальних вікон для підтвердження видалення об'єктів та введення назв.

Додаток демонструє можливість створення кросплатформових системних інструментів із нативною швидкістю роботи та зручним UI.
